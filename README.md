# Madeixa

Visagista pessoal com IA que sugere cortes de cabelo para o formato do seu rosto.

🔗 **Demo:** https://bertmartins.github.io/Madeixa/

## 🛠️ Tecnologias

- HTML
- JavaScript
- API de IA

## 🚀 Como executar

```bash
git clone https://github.com/BertMartins/Madeixa.git
cd Madeixa
```

Abra o arquivo `index.html` no navegador ou acesse a demo acima.
